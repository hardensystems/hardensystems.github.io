Posting a video should be enough to start a website draft. This test starts with a public TikTok upload and follows it through to a draft article with an embedded player.

IFTTT picked up the test upload and emailed its video ID, link, and publication time. Intake used the ID to check for duplicates, then matched it to the original TikTok URL. The draft uses that same ID in the player and includes a direct link for readers.
